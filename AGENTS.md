# Adiosbox

Adiosbox is Ryan's personal AI playground. Build and maintain it locally, with a static visitor-facing site on Hugo and Cloudflare Pages. Keep contributions easy to resume, with short commands and accessible controls. Each experiment should explain itself and be readable without an API key.

Only send the visitor's key and inputs to OpenRouter when they explicitly run an experiment. Keep keys out of persistent browser storage, URLs, server configuration, logs, and source. Keep sharing links limited to the public experiment. Avoid introducing accounts or backend services for the playground without an explicit need.

Run focused checks. Staging, commits, pushes, deployment, publication, and domain changes each require Ryan's explicit authorization.
